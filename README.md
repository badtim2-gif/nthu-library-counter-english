# 清大圖書館英語情境練習室

以清大圖書館櫃台服務為背景的中英雙語教學 PWA，包含 20 個情境、角色扮演、句型與文法說明、單字解說，以及預錄離線語音。

## 線上使用

https://badtim2-gif.github.io/nthu-library-counter-english/

## 內容規格

- 讀者與館員各 3 次發言，共 6 次交替發言
- 英文約 120 WPM
- 中文使用台灣華語聲線
- 支援全文、單句播放、暫停、續播與角色隱藏
- 支援 PWA 安裝與離線語音下載

政策資訊附官方來源與查核日期；實際服務資格與規定仍以清大圖書館最新公告為準。

## 查看音訊版本

- 在「下載離線語音／離線語音已備妥」區查看「音訊版本」；手機可往下捲至該區。本輪 thesis 修正版為 `v22`。
- 此標示與實際播放、離線下載使用相同版本常數；若仍顯示舊版，請關閉舊分頁後重新開啟網站再確認。
- thesis 單字檔沿用情境08對話01中已確認正確的同一段發音，裁切範圍、來源雜湊記在 `tests/audio-manifest.json` 的 `source_segment`，避免再次獨立合成造成差異。
- 使用 `scripts/generate-kokoro-audio.py` 重建這類衍生單字時，需額外提供 `--reference-audio-dir public/audio`；來源雜湊或裁切範圍不符即停止，不悄悄改用獨立合成。
- 不可把已核准的來源對話與其衍生單字一起重製；若需更換來源對話，應先審聽新來源並更新雜湊及裁切範圍。
